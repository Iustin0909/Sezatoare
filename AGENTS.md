# Proiect: Șezătoare Râmnicu Vâlcea

## Despre Proiect
Platformă web dedicată comunității „Șezătoare Râmnicu Vâlcea”, creată pentru păstrarea și promovarea tradițiilor românești, a iei și a portului popular.

## Structură fișiere
- `index.html`: Pagina web principală (secțiuni: Despre, Tradiție, Evenimente, Contact).
- `styles.css`: Stiluri CSS, fonturi și adaptabilitate responsive.
- `README.md`: Documentația proiectului.

## Ghid pentru agenți și dezvoltare
- Comunicarea și comentariile se fac în limba română.
- Menținerea stilului curat, semantic și accesibil.
- Modificările validate se salvează prin commit pe ramura `main` și se sincronizează pe GitHub.
